## 📘 Course Description
Introduction to multiobjective optimization. Topics include:
- Basic foundations
- Pareto optimality
- A-posteriori, A-priori, and interactive preference articulation methods
- Performance metrics for evaluating non-dominated solutions
- Linear, nonlinear, and combinatorial multiobjective optimization problems
- Applications in planning, engineering, and data science
- Computational implementation of exact methods and multiobjective metaheuristics

---

## 🎯 Rationale
Many real-world problems in engineering, logistics, planning, energy systems, transportation, and data science involve multiple conflicting objectives. Multiobjective optimization provides a framework for modeling and solving such problems, enabling efficient solutions and supporting decision-making. Advances in metaheuristics have expanded the ability to solve large-scale practical problems.

---

## 🎓 Course Objectives
By the end of the course, students will be able to:
1. Understand the theoretical foundations of multiobjective optimization  
2. Evaluate solution sets using performance metrics  
3. Model linear, nonlinear, and combinatorial problems  
4. Implement optimization algorithms in Python  
5. Apply methods to real-world problems
