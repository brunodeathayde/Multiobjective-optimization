# Multiobjective Optimization

This repository contains the teaching materials, computational examples, assignments, and project guidelines for the course **Multiobjective Optimization**.

Multiobjective optimization addresses decision-making problems involving two or more conflicting objectives that must be optimized simultaneously. Unlike single-objective optimization, these problems generally do not have a single optimal solution. Instead, they give rise to a set of efficient solutions, known as the **Pareto-optimal set**, which represent different trade-offs among the objectives.

The course provides a comprehensive introduction to the theoretical foundations and computational methods of multiobjective optimization. Topics include Pareto optimality, Pareto frontiers, a-priori, a-posteriori, and interactive preference articulation methods, as well as performance metrics for evaluating non-dominated solution sets. Students are also exposed to linear, nonlinear, and combinatorial multiobjective optimization problems.

A significant component of the course is devoted to computational practice using Python. The repository includes implementations of classical approaches such as the weighted-sum method and the ε-constraint method, along with tools for computing quality indicators, including hypervolume and coverage metrics. Advanced topics include the application of multiobjective metaheuristics and evolutionary algorithms for solving large-scale and complex optimization problems.

Throughout the semester, students develop practical skills in modeling, analyzing, and solving real-world problems arising in engineering, logistics, transportation, energy systems, manufacturing, and data science. The course emphasizes both methodological rigor and practical implementation.

The materials provided in this repository are intended to support classroom activities, independent study, and project development. They include lecture notes, datasets, Python notebooks, programming exercises, and supplementary references.

By the end of the course, students should be able to formulate multiobjective optimization models, identify and analyze Pareto-optimal solutions, evaluate solution quality using appropriate metrics, and apply state-of-the-art optimization techniques to complex decision-making problems.
