# 📊 Performance Metrics for Multi-Objective Evolutionary Algorithms (MOEAs)

An implementation of standard performance metrics used to evaluate and compare non-dominated solution sets generated by **Multi-Objective Evolutionary Algorithms (MOEAs)**, based on **Chapter 8 of K. Deb (2001/2021)**: *"Salient Issues of MOEAs"*.

---

## 📌 Overview

This project benchmark and evaluates two discrete solution sets (**Approximation A** and **Approximation B**) against a continuous, non-convex true Pareto front ($f_1^2 + f_2^2 = 1, f_1, f_2 \ge 0$).

### Key Properties of the Setup:
* **Approximation A ($\vert{}A\vert{} = 8$):** Higher convergence on the left region ($f_1 \le 0.64$).
* **Approximation B ($\vert{}B\vert{} = 12$):** Higher convergence on the right region ($f_1 > 0.64$).
* **Full Coverage:** Both approximations cover the entire Pareto front without central gaps.
* **Pareto Validity:** All solutions in $A$ and $B$ are strictly dominated by the continuous true Pareto front and internal solutions are non-dominated relative to their respective sets.

---

## 📈 Implemented Metrics

| Metric | Code | Indicator Type | Description | Optimization Goal |
|---|---|---|---|---|
| **Error Ratio** | `ER` | Convergence | Proportion of solutions not belonging to the true Pareto front (within tolerance $\epsilon$). | **Minimize** $\rightarrow 0$ |
| **Generational Distance** | `GD` | Convergence | Average Euclidean distance from approximation points to the nearest point on the true front. | **Minimize** $\rightarrow 0$ |
| **Spacing** | `S` | Diversity | Relative variance of distance between neighboring solutions (uniform distribution test). | **Minimize** $\rightarrow 0$ |
| **Spread** | $\Delta$ | Diversity | Evaluates both extent of coverage and uniformity of point distribution. | **Minimize** $\rightarrow 0$ |
| **Hypervolume** | `HV` | Combined | Volume of the objective space dominated by the solution set relative to a reference point $(1.4, 1.4)$. | **Maximize** |
| **Number of Non-Dominated Solutions** | `NNDS` | Quantity | Total count of valid non-dominated points retained in the set. | **Maximize** |
